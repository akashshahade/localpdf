# LocalPDF

Free in-browser PDF tools. Files never leave the device.

Live site: [https://www.editlocalpdf.com](https://www.editlocalpdf.com)

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
